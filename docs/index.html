苹果日历操作

  1. 打开 iPhone 自带「日历」App。
  2. 点击底部「日历」→「添加日历」→「添加订阅日历」。
  3. 粘贴上方订阅网址，点击「查找」，确认订阅。
  4. 可把日历命名为「湖人中文赛程」，设置紫色。

订阅刷新由苹果系统控制，不保证比赛调整后立即显示；NBA 数据接口暂时故障时会保留上一次成功的日历版本。
